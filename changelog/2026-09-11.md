## 16:48 — `feature` — takehome-scaffold — Reproducible EducationPals course-generation repository and offline review setup

**Type**
feature

**Ask**
"I want the setup ready, create a git repo and push the setup to it, create folders,
add dependencies, etc." The request followed the full EducationPals AI Engineer
take-home brief, including its required submission layout, AI-generated content,
offline replay, Python 3.12, and under-10-MB archive constraints.

**Plan**
The review emphasizes generation process and build reliability more than prose.
A one-shot course prompt would make the required design order invisible and would
make failures hard to reproduce. The setup therefore separates diagnostic,
planning, lesson-writing, critic, and revision stages; passes typed artifacts
between them; and saves sanitized response envelopes for exact offline replay.
Evals and LLM-as-Judge was selected as the initial configurable topic because its
precision/recall capstone has an objective terminal check. Deterministic
validators enforce limits and safe generated paths in addition to the model
critic. A stdlib packager was chosen over another dependency so archive creation
stays portable and auditable.

**Action**
Created the required course, build, output, agent, and writeup layout; pinned
Python and runtime dependencies; implemented strict Pydantic generation schemas,
live Responses API generation with `store=False`, prompt-hash cache replay,
deterministic plan/lesson validation, safe artifact rendering, staged critique
and revision, offline setup verification, and an under-10-MB submission
packager. Added focused unit tests and initialized the repository on `main`.

**Result**
- Verification: Python 3.12.14 compiled all Python sources; six unit tests passed
  in a clean virtual environment; `python -m agent verify` reported PASS; the
  installed OpenAI 3.12.0 SDK exposes the used `responses.parse` parameters; a
  test archive was produced at 22.8 KiB.
- Not verified: no paid live model generation was run, so `course/`, `build/`,
  and response caches remain intentional setup markers rather than final content.
- Outcome: the project can now generate, validate, cache, replay, inspect, and
  package the take-home without placing an API key in the repository.
