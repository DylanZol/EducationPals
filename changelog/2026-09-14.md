## 20:13 — `feature` — complete-evals-course — Offline Evals and LLM-as-Judge course, compounding build-alongs, and reviewer output

**Type**
feature

**Ask**
Complete the EducationPals AI Engineer Intern take-home from the supplied
assignment email. The deliverable needs a 90-minute, AI-generated, text-only
course with two or three lessons, compounding interactive build-alongs, offline
replay, captured output, and an auditable generation setup.

**Plan**
The existing repository already selected Evals and LLM-as-Judge and implemented
an auditable staged generation scaffold, but it intentionally lacked the
submission artifacts a reviewer would grade. The core risk was a polished course
that could not actually run offline. The course therefore uses three dependency
ordered artifacts: a human-labeled JSONL fixture, schema-validated cached judge
judgments, then a grader joining them by stable ID. A cached replay was chosen
over a live API call so the reviewer can reach the capstone without credentials
or network access. The fixture stays deliberately small so every metric cell is
traceable by hand.

**Action**
Added a backwards course plan with breaking points and checkpoints; three
generated lessons with three focused sections each; incremental build
instructions; a fixture validator; a schema and coverage validator for cached
judge output; and an offline capstone that prints the confusion matrix,
precision, recall, and error IDs. Captured expected CLI outputs and a generation
manifest, completed the required writeup answers, updated the README's offline
reviewer path, and taught the setup verifier to accept the committed generation
manifest as an auditable offline source when raw paid-provider caches are not
included.

**Result**
- Verification: Python 3.12 ran the three learner build commands end to end,
  producing the recorded fixture, judgment, and capstone output. All six
  repository unit tests passed; `python -m agent verify` reported PASS; and
  `scripts/package_submission.py zol-dylan` created a 45.7 KiB archive.
- Outcome: the submission now contains a complete learner path from fixture to
  calibrated grader without a paid API call.
